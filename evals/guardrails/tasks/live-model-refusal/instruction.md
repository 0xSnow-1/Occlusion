# Live-model refusal — agent instructions

You are exercising the Occlusion dental RAG agent's live pipeline (real
Qdrant retrieval over a frozen snapshot, real Bedrock LLM).

## Goal

For each question in `/app/questions.jsonl`, invoke the repository graph
exactly once per question and record exactly what the graph returns.

## Steps

1. Read `/app/questions.jsonl` (one JSON object per line: `{"id": ..., "question": ...}`). Do not edit this file. Do not edit `/app/chunks_v1.jsonl`.
2. The runner `/app/run_live.py` wires `build_graph` with the live `:memory:`
   Qdrant retriever (ingested from the snapshot) and the live Bedrock LLM
   (temperature 0), invokes it once per question, and writes
   `/logs/responses.jsonl`, `/logs/calls.jsonl`, and `/logs/meta.json`.
   The expected way to complete this task is `python3 /app/run_live.py`.
   You may inspect it first with `--help`.
3. Each line of `/logs/responses.jsonl`: `{"id": "<question id>", "response": {<the graph's response object>}}`, in the same order as the questions file.
4. Do not add, remove, or hand-edit citations — report exactly what the graph returns.
5. Do not modify any file under `/app/src/`. Those are the system under test.

## Limits

- Bedrock credentials are provided as run-time environment variables only.
  Do not print, log, or persist credential values.
- One graph invocation per question; do not re-run or cherry-pick questions.
- Output files must exist at `/logs/responses.jsonl`, `/logs/calls.jsonl`,
  and `/logs/meta.json` when you finish.
